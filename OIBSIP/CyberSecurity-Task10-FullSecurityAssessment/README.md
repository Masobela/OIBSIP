# Task 10: Full Network Security Assessment Report

## What I'm Doing
This is the "final boss" task — I'm combining everything from the tasks before it (Nmap, Wireshark, Nikto) into one complete security check-up of a test network, and writing it up like a real professional security report.

Steps:
1. **Recon** — find all devices, open ports, and services (Nmap)
2. **Traffic Analysis** — capture and study network traffic (Wireshark)
3. **Web Scan** — check any web server for weaknesses (Nikto)
4. Then I pull it all together into one findings report with a priority list of what to fix first.

## Why It Matters
This is basically a mini version of what a real cybersecurity analyst does for a company: look at a network from every angle, find the risks, and explain them clearly to both technical teams and managers.

## What I'll Produce
- `network_security_assessment.md` — the full report
- `nmap_results.txt` and `wireshark_capture.pcap`
- A findings table (what's wrong, how bad it is, how to fix it)
- A 1-page summary for a non-technical manager
- A remediation roadmap (what to fix first, and how hard each fix is)

- Nmap, Wireshark, Nikto
- Markdown (for the report)
