# Task 5: Research Report — Social Engineering Attacks

## What I'm Doing
I'm writing a report about **social engineering** — attacks that trick *people*, not computers. These include:
- **Phishing** — fake emails/texts/calls pretending to be someone trustworthy
- **Pretexting** — making up a fake story to get someone to share information
- **Baiting** — leaving something tempting (like a USB drive) to trick someone into using it
- **Quid Pro Quo** (bonus) — offering a "favor" in exchange for information or access

## Why It Matters
Most hacks don't start with clever code — they start with tricking a person. Understanding these tricks is one of the best ways to avoid falling for them.

- A comparison table
