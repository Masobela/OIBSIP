# Task 4: Research Report — Common Network Security Threats

## What I'm Doing
I'm writing a research report (no hands-on hacking here — just research and writing) about four common ways attackers try to break networks:
1. **DoS/DDoS** — flooding a system with traffic so it can't work
2. **Man-in-the-Middle (MITM)** — secretly listening in or changing messages between two people/computers
3. **IP Spoofing** — pretending to be a different computer than you really are
4. **DNS Poisoning** — tricking a computer into visiting a fake website instead of the real one

For each one, I explain how it works, give a real example that actually happened, and list ways to defend against it.

## Why It Matters
You can't defend against something you don't understand. This report is basically my "cheat sheet" on the most common attacks, written so anyone could understand it.
