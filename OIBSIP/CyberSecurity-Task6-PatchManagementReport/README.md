# Task 6: Research Report — The Importance of Patch Management

## What I'm Doing
I'm writing a report about **patch management** — the process of regularly updating software to fix security holes. Think of patches like "band-aids" that companies release when they find a weakness in their software.

I'll explain why skipping updates is dangerous, using real examples like the WannaCry ransomware attack, which spread because many computers hadn't installed a security fix that was already available.

## Why It Matters
A huge number of hacks happen not because of some super advanced trick, but simply because a company didn't install an update that was already available for months or years.
